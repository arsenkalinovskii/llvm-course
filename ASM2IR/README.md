# ISA и ассемблер
### В файле `asm_description.md` описан набор инструкций для придуманного асемблера.
### Файл `asm1.s` -- простой файл, который сразу выходит.
### Файл `app.s` -- переписанное на ассемблер приложение.

# ASM2IR генератор
### `asm2ir_1.cpp` -- с вызовами эмулирующих инструкции функций (кроме инструкций потока управления) + запуск на Execution Engine.

### `asm2ir_2.cpp` -- с генерацией IR эквивалентов для всех инструкций + запуск на Execution Engine.

### `asm2ir_3.cpp` -- симуляция без генерации IR, только на вызовах эмулирующих инструкции функций.
